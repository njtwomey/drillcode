Given an integer array `nums` and an integer `target`, put a `+` or `-` sign in front of every element and evaluate the resulting expression. Return the number of different sign assignments whose value equals `target`. Assignments are distinguished by position, so two zeros give four different choices even though they contribute the same value.

Constraints:
- `1 <= len(nums) <= 20`
- `0 <= nums[i] <= 1000`, with `sum(nums) <= 1000`
- `-1000 <= target <= 1000`
- `nums` may contain zeros
