Given an integer array `nums` and an integer `target`, return all unique quadruplets `[nums[a], nums[b], nums[c], nums[d]]` where `a`, `b`, `c`, `d` are four distinct indices and the four values sum to `target`. No two returned quadruplets may contain the same multiset of values. The quadruplets may be returned in any order.

Constraints:
- `1 <= len(nums) <= 200`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- `nums` may contain many duplicates
