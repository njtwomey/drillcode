Given an array `nums` sorted in non-decreasing order and an integer `target`, return a two-element list `[first, last]` holding the index of the first and the index of the last occurrence of `target` in `nums`. If `target` does not appear, return `[-1, -1]`. Duplicates are allowed, so the occurrences can form a run of any length.

Constraints:
- `0 <= len(nums) <= 10^5`
- `-10^9 <= nums[i], target <= 10^9`
- `nums` is sorted in non-decreasing order
- The solution must run in O(log n) time
