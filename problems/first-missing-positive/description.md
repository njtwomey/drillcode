Given an unsorted integer array `nums`, return the smallest positive integer (1, 2, 3, ...) that does not appear in it. The array may contain negatives, zeros, duplicates and values far larger than its length.

Constraints:
- `1 <= len(nums) <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- Required: O(n) time using O(1) extra space (the input array may be modified)
