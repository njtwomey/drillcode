Two non-empty linked lists `l1` and `l2` each represent a non-negative integer with one decimal digit per node, stored in reverse order (least significant digit first). Return the head of a new linked list representing their sum in the same format.

Constraints:
- Each list has 1 to 100 nodes
- Digits are `0` to `9`
- No leading zeros, except the number `0` itself
- Numbers may be too large for a fixed-width integer
