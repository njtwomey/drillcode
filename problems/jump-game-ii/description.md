You start at index 0 of an integer array `nums`, where `nums[i]` is the maximum distance you can jump forward from index `i` (any shorter jump is also allowed). Return the minimum number of jumps needed to reach the last index.

The test data guarantees the last index is always reachable. An array of length 1 needs 0 jumps.

Constraints:
- `1 <= len(nums) <= 10^4`
- `0 <= nums[i] <= 1000`
- The last index is reachable from index 0
