Given an integer array `nums` that may contain duplicates, return every distinct permutation of its elements. Two permutations are the same if they are equal as sequences of values, regardless of which equal elements ended up where, so each distinct arrangement must appear exactly once.

The permutations may be returned in any order, but the order of values inside each permutation matters.

Constraints:
- `1 <= len(nums) <= 8`
- `-10 <= nums[i] <= 10`
- `nums` may contain duplicates
