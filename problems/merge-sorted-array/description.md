You get two integer arrays, `nums1` and `nums2`, each sorted in non-decreasing order, along with `m` and `n`, the number of real elements in each. `nums1` has length `m + n`: its first `m` slots hold real values and the last `n` are zero placeholders reserved for the result.

Merge the elements of `nums2` into `nums1` so that `nums1` ends up as one sorted array of all `m + n` values. Nothing is returned; `nums1` is modified in place.

Constraints:
- `0 <= m, n <= 200` and `1 <= m + n <= 200`
- Values are in `[-10^9, 10^9]`
- No extra array proportional to the input should be needed
