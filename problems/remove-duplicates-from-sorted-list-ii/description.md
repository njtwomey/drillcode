Given the `head` of a sorted (ascending) singly linked list, delete every node whose value appears more than once, so that only values that occurred exactly once remain. Return the head of the resulting list, which stays sorted. Unlike the keep-one version of this task, a duplicated value is removed completely.

Constraints:

- 0 to 300 nodes
- Node values are between -100 and 100
- The input is sorted in ascending order
