Given an integer array `nums` and an integer `k`, return the number of contiguous, non-empty subarrays whose elements sum to exactly `k`. Subarrays are counted by position, so equal-looking subarrays at different places each count.

Elements and `k` can be negative or zero, so the array is not monotone in any sense.

Constraints:
- `1 <= len(nums) <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`
