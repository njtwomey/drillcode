Given an array of positive integers `candidates` (which may contain duplicates) and an integer `target`, return all unique combinations of candidates that sum to `target`. Each element of `candidates` may be used at most once, and two combinations are the same if they use the same values the same number of times, even if drawn from different positions.

The combinations and the values within them may be returned in any order.

Constraints:
- `1 <= len(candidates) <= 100`
- `1 <= candidates[i] <= 50`
- `1 <= target <= 30`
- The result must not contain duplicate combinations
