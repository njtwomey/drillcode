Given an unsorted integer array `nums`, return the length of the longest run of values that are consecutive integers (each one greater than the last by exactly 1). The values may appear anywhere in the array, in any order, and duplicates are allowed. Return `0` for an empty array.

Constraints:
- `0 <= len(nums) <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- Must run in O(n) time
