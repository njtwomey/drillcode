A window of size `k` moves one position at a time from the left end of `nums` to the right end. Return a list holding the maximum value in the window at each position, in order (`len(nums) - k + 1` values).

Constraints:
- `1 <= len(nums) <= 10^5`
- `1 <= k <= len(nums)`
- Values lie in [-10^4, 10^4]
- Aim for better than O(`len(nums)` * `k`)
