`points` holds 2D points `[x, y]`. Return the `k` points closest to the origin `(0, 0)` by Euclidean distance. The result may be in any order.

Constraints:
- `1 <= k <= len(points) <= 10^4`
- `-10^4 <= x, y <= 10^4`
- The set of `k` closest points is guaranteed to be unique (no ties at the cutoff).
