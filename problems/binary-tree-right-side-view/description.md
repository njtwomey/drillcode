Given the `root` of a binary tree, return the values of the nodes visible when looking at the tree from its right side, ordered from top to bottom. At each depth, that is the rightmost node of the level. Return an empty list for an empty tree.

Constraints:
- 0 to 100 nodes
- Node values are in `[-100, 100]`
- A deeper left subtree can still be visible where the right side is shorter
