`tokens` is an arithmetic expression in reverse Polish notation. Each token is an integer string or one of the operators `+`, `-`, `*`, `/`. Evaluate the expression and return the integer result. Division between integers truncates toward zero.

Constraints:
- The expression is always valid.
- There are no divisions by zero.
- `1 <= len(tokens) <= 10^4`
- Every intermediate result and the final result fit in a 32-bit signed integer.
