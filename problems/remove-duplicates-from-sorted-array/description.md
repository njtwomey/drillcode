Given an integer array `nums` sorted in non-decreasing order, remove duplicates in place so that each distinct value appears once, keeping their relative order. Return `k`, the number of distinct values, and arrange `nums` so that its first `k` elements are those values in order. What is stored beyond index `k` does not matter.

Do not allocate another array for the result.

Constraints:

- `1 <= nums.length <= 3 * 10^4`
- Values are between -100 and 100
- Extra memory should be O(1)
