`head` is the head of a singly linked list in which every node has a `next` pointer and a `random` pointer. `random` points to any node in the list or is `None`. Return the head of a deep copy: every node in the copy must be newly created, and the copied `next` and `random` pointers must reference only nodes of the copy, preserving the original structure. The input list must not be modified. Return `None` for an empty list.

Constraints:
- Up to 1000 nodes.
- Node values may repeat.
