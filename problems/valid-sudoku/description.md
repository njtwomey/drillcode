Given a partially filled 9x9 Sudoku `board`, return `True` if the filled cells do not break any rule, otherwise `False`. Only filled cells are checked: each row, each column and each of the nine 3x3 sub-boxes must contain no repeated digit from `"1"` to `"9"`. The board need not be solvable.

Constraints:
- `board` is 9x9 and each cell is a digit character `"1"`-`"9"` or `"."` for empty
