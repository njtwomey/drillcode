Given the `head` of a singly linked list, return the node where a cycle begins, that is, the first node reached again when following `next` pointers around the loop. If the list has no cycle, return `null`.

The list may be empty. The cycle, if any, is formed by the tail's `next` pointing back at some earlier node (or itself). The list must not be modified.

Constraints:

- Up to 10^4 nodes
- Aim for O(1) extra memory
