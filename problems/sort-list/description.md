Given the `head` of a singly linked list, sort the nodes by value in ascending order and return the head of the sorted list. The list may be empty and may contain duplicate and negative values.

Constraints:

- Up to 5 * 10^4 nodes
- Values are between -10^5 and 10^5
- Aim for O(n log n) time; an O(1) extra space solution (beyond recursion) is the stretch goal
