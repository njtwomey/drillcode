Given an array of strings `words` and an integer `k`, return the `k` most frequent distinct words. The result is ordered from most to least frequent; words with the same frequency are ordered alphabetically (standard lexicographic order).

Constraints:
- `1 <= len(words) <= 500`
- Each word has 1 to 10 lowercase English letters
- `1 <= k <=` the number of distinct words
- Aim for O(n log k) time
