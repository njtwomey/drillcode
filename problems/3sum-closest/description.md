Given an integer array `nums` and an integer `target`, choose three elements at distinct indices so that their sum is as close to `target` as possible, and return that sum. The array has at least three elements, and exactly one sum is closest.

The array may be reordered or modified.

Constraints:

- `3 <= nums.length <= 500`
- Values are between -1000 and 1000
- `target` is between -10^4 and 10^4
