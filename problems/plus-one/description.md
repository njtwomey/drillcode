A non-negative integer is stored as an array `digits`, most significant digit first, one decimal digit per element. Return the array representing that integer plus one.

The input has no leading zeros, except that the number zero is the single element `[0]`. The array may be modified or a new one returned.

Constraints:
- `1 <= len(digits) <= 100`
- Each element is between 0 and 9
- The value may exceed any fixed-width integer if you convert it, so work on the digits directly
