An ascending array of distinct integers `nums` has been rotated at an unknown pivot (for example, `[0,1,2,4,5,6,7]` may become `[4,5,6,7,0,1,2]`). Return the index of `target` in `nums`, or `-1` if it is absent.

Constraints:

- Must run in O(log n) time
- All values are distinct
- `1 <= len(nums) <= 5000`
- The array may be unrotated
