Given the `head` of a singly linked list, swap every two adjacent nodes (1st with 2nd, 3rd with 4th, and so on) and return the new head. If the length is odd, the final node stays where it is.

Swap the nodes themselves by relinking; changing the stored values is not allowed.

Constraints:

- 0 to 100 nodes
- Node values are between 0 and 100
