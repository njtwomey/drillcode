Given the `root` of a binary tree, return its node values level by level, alternating direction: the first level (the root) is listed left to right, the next right to left, the next left to right again, and so on. The result is a list of lists, one per level, and an empty tree gives an empty list.

Constraints:

- Up to 2000 nodes
- Node values lie in [-100, 100]
