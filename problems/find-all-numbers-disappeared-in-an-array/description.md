Given an array `nums` of `n` integers where every value lies in the range `[1, n]` (duplicates are allowed), return all integers in `[1, n]` that do not appear in `nums`. The result may be in any order.

Constraints:
- `1 <= n <= 10^5`
- `1 <= nums[i] <= n`
- Follow-up: O(n) time with no extra space beyond the output (the input may be modified)
