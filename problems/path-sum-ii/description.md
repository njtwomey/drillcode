Given the `root` of a binary tree and an integer `targetSum`, return every root-to-leaf path whose node values add up to `targetSum`. Each path is a list of node values from the root down to the leaf. A leaf is a node with no children. The paths may be returned in any order, and an empty list is returned when none match.

Constraints:

- Up to 5000 nodes
- Node values and `targetSum` lie in [-1000, 1000], so values can be negative or zero
