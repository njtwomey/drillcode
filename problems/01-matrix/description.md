Given an `m x n` binary matrix `mat`, return a matrix of the same shape in which each cell holds the distance to the nearest `0` in `mat`. Distance is measured between orthogonally adjacent cells, so each step up, down, left or right counts as 1.

`mat` contains at least one `0`.

Constraints:
- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^4`
