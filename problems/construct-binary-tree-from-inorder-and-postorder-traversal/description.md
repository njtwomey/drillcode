Given two integer arrays `inorder` and `postorder`, the inorder and postorder traversals of the same binary tree, rebuild the tree and return its root. Both arrays have the same length and contain the same values, and every value appears only once, so the tree is uniquely determined.

Constraints:

- Between 1 and 3000 nodes
- Node values lie in [-3000, 3000] and are all distinct
- `postorder` is guaranteed to be a valid postorder of the tree whose inorder is `inorder`
