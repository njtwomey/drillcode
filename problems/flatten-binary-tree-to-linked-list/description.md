Given the `root` of a binary tree, flatten it in place into a linked list that uses the tree nodes themselves. Every node's `right` pointer must point to the next node in preorder (node, left subtree, right subtree) and every `left` pointer must be `None`. Return nothing; the tree rooted at `root` is modified directly.

Constraints:

- Up to 2000 nodes
- Node values lie in [-100, 100]
- Extra space beyond the nodes themselves should ideally be constant
