Given strings `s` and `p`, return the starting indices of every substring of `s` that is an anagram of `p` (a rearrangement using exactly the same characters). Matches may overlap. Indices may be returned in any order; return an empty list if there are none.

Constraints:
- `1 <= len(s), len(p) <= 3 * 10^4`
- Both strings consist of lowercase English letters
- `p` may be longer than `s`
