Given an integer array `nums` that may contain duplicate values, return every distinct subset (the power set without repeats). Two subsets are the same if they hold the same values with the same multiplicities, regardless of which positions the values came from. The empty subset is included.

The subsets may be returned in any order, and the elements inside a subset may be in any order.

Constraints:
- `1 <= len(nums) <= 10`
- `-10 <= nums[i] <= 10`
- `nums` is unsorted and may contain duplicates
