Given an array of coin denominations `coins` and an integer `amount`, return the minimum number of coins needed to make exactly `amount`, with unlimited supply of each denomination. Return `-1` if the amount cannot be formed, and `0` when `amount` is `0`.

Constraints:
- `1 <= len(coins) <= 12`
- `1 <= coins[i] <= 2^31 - 1`, all distinct
- `0 <= amount <= 10^4`
