Given a string `num` representing a non-negative integer and an integer `k`, delete exactly `k` digits from `num` so that the remaining number is as small as possible. Keep the surviving digits in their original order. Return the result as a string with no leading zeros; if nothing is left, or only zeros, return `"0"`.

Constraints:
- `1 <= k <= len(num) <= 10^5`
- `num` has only digits and no leading zeros
