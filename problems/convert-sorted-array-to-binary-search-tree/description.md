Given an integer array `nums` sorted in strictly ascending order, build a binary search tree containing exactly those values and return its root. The tree must be height balanced: for every node, the heights of its left and right subtrees differ by at most one. Several different trees can satisfy this, and any of them is accepted.

Constraints:

- Between 1 and 10000 values
- Values lie in [-10^4, 10^4] and are distinct
