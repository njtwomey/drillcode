Given a string `digits` of characters `2`-`9`, return every letter string the digits could spell on a standard telephone keypad (2 = abc, 3 = def, 4 = ghi, 5 = jkl, 6 = mno, 7 = pqrs, 8 = tuv, 9 = wxyz). Choose one letter per digit, in digit order. Results may be in any order. If `digits` is empty, return an empty list.

Constraints:
- `0 <= len(digits) <= 4`
- Each character of `digits` is in `'2'..'9'`
