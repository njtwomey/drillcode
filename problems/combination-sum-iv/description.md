Given an array of distinct positive integers `nums` and an integer `target`, return the number of sequences of elements of `nums` (elements reusable, order significant) that sum to `target`. For example, different orderings of the same values count as different sequences.

Constraints:
- `1 <= len(nums) <= 200`
- `1 <= nums[i] <= 1000`, all distinct
- `1 <= target <= 1000`
- The answer fits in a 32-bit signed integer
- Follow-up: negative numbers in `nums` would require an extra restriction
