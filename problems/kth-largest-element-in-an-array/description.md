Return the `k`-th largest element of `nums` in sorted order. Duplicates count separately, so this is not the `k`-th distinct value. `k` is always valid (`1 <= k <= len(nums)`).

Constraints:
- `1 <= len(nums) <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- A full sort is not the intended solution; aim for better than O(n log n) on average or O(n log k)
