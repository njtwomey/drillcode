Implement `MinStack`, a stack that also reports its minimum. All operations are called on a non-empty stack, except `push`.

- `MinStack()`: create an empty stack.
- `push(val)`: push `val` onto the stack. Returns nothing.
- `pop()`: remove the top element. Returns nothing.
- `top()`: return the top element without removing it.
- `getMin()`: return the smallest element currently in the stack.

Constraints:
- `-2^31 <= val <= 2^31 - 1`
- Up to `3 * 10^4` calls
- Every operation must run in O(1) time
