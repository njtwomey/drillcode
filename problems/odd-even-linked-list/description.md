Given the `head` of a singly linked list, regroup it so that all nodes at odd positions (1st, 3rd, 5th, ...) come first, followed by all nodes at even positions. Position means place in the original list, not the node's value. Within each group, keep the original relative order. Return the new head.

Constraints:

- Up to 10^4 nodes (the list may be empty)
- Must run in O(n) time using O(1) extra space, so relink nodes rather than copying values
