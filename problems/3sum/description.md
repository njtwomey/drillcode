Given an integer array `nums`, return all triplets `[nums[i], nums[j], nums[k]]` with distinct indices `i`, `j`, `k` whose values sum to 0. The result must not contain duplicate triplets (as multisets of values). Triplets and the order within each may be returned in any order; return an empty list if none exist.

Constraints:
- `3 <= len(nums) <= 3000`
- Values are in `[-10^5, 10^5]`
- `nums` may contain duplicates
- O(n^2) time is expected
