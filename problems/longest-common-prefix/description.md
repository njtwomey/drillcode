Given an array of strings `strs`, return the longest string that is a prefix of every string in the array. If there is no common prefix, return the empty string `""`.

Strings in the array may be empty, and the array may contain a single string.

Constraints:
- `1 <= len(strs) <= 200`
- `0 <= len(strs[i]) <= 200`
- Each string consists of lowercase English letters only
