Return `True` if the string `s` can be split into a sequence of one or more words, all taken from `wordDict`, otherwise `False`. Each dictionary word may be used any number of times.

Constraints:
- `1 <= len(s) <= 300`
- `1 <= len(wordDict) <= 1000`, each word 1-20 characters
- All characters are lowercase English letters
- All words in `wordDict` are unique
