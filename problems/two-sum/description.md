Given an integer array `nums` and an integer `target`, return the indices of two different elements whose values sum to `target`. Exactly one valid pair exists, and the same element may not be used twice. Indices are 0-based and may be returned in any order.

Constraints:
- `2 <= len(nums) <= 10^4`
- Values and `target` are in `[-10^9, 10^9]`
- `nums` may contain duplicates and is not sorted
- Aim for better than O(n^2) time
