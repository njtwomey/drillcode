Given two strings `s1` and `s2`, return `true` if some substring of `s2` is a rearrangement of all the characters of `s1` (same letters with the same multiplicities, contiguous in `s2`), otherwise `false`.

Constraints:
- `1 <= len(s1), len(s2) <= 10^4`
- Both strings consist of lowercase English letters
- `s1` may be longer than `s2`
