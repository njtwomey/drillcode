`lists` is an array of singly linked lists, each sorted in ascending order. Merge them into one ascending sorted linked list and return its head, or `None` if there are no nodes at all.

Constraints:
- `0 <= len(lists) <= 10^4`; individual lists may be empty
- Total number of nodes across all lists is at most 10^4
- Node values lie in [-10^4, 10^4]
