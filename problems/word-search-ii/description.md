Given a grid of lowercase letters `board` and a list `words`, return every word from `words` that can be spelled by a path of horizontally or vertically adjacent cells. A cell may not be reused within a single word's path. Return each found word once, in any order.

Constraints:
- `board` is at most 12x12
- `1 <= len(words) <= 3 * 10^4`, each word 1-10 lowercase letters
- All words in `words` are unique
