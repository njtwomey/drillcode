Given `intervals`, where `intervals[i] = [start, end]` is a meeting's half-open time span, return the minimum number of rooms needed to hold all meetings with no two overlapping in the same room. A meeting ending at time `t` does not conflict with one starting at `t`. The input is unsorted.

Constraints:
- `1 <= len(intervals) <= 10^4`
- `0 <= start < end <= 10^6`
