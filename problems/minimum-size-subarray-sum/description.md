Given an array of positive integers `nums` and a positive integer `target`, return the minimal length of a contiguous subarray whose sum is at least `target`. If no subarray reaches `target`, return `0`.

Constraints:
- `1 <= target <= 10^9`
- `1 <= len(nums) <= 10^5`
- `1 <= nums[i] <= 10^4`
- Quadratic time is too slow at the upper limit
