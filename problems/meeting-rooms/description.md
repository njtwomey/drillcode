`intervals[i] = [start, end]` is the time span of a meeting. Return `True` if one person can attend every meeting, meaning no two meetings overlap, and `False` otherwise. Meetings where one ends exactly when another starts do not overlap.

Constraints:

- `0 <= len(intervals) <= 10^4`
- `0 <= start < end <= 10^6`
- `intervals` is not guaranteed to be sorted
