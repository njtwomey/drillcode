Given `intervals`, where `intervals[i] = [start, end]`, return the minimum number of intervals to remove so that the remaining ones do not overlap. Intervals that only touch at an endpoint (such as `[1,2]` and `[2,3]`) do not overlap. Identical intervals do overlap.

Constraints:
- `1 <= len(intervals) <= 10^5`
- `-5 * 10^4 <= start < end <= 5 * 10^4`
