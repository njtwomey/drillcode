Given the `root` of a binary tree and an integer `targetSum`, return `True` if some root-to-leaf path has node values that add up exactly to `targetSum`, and `False` otherwise. A leaf is a node with no children, so a path that stops at a node with one child does not count. An empty tree has no paths.

Constraints:

- Up to 5000 nodes
- Node values and `targetSum` lie in [-1000, 1000], so values can be negative and partial sums are not monotonic
