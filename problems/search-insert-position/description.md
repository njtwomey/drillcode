Given a sorted array `nums` of distinct integers and an integer `target`, return the index of `target` if it is in the array. Otherwise return the index where it would have to be inserted to keep the array sorted. That index can be `len(nums)` when `target` is larger than every element.

Constraints:
- `1 <= len(nums) <= 10^4`
- `nums` is sorted in ascending order with no duplicates
- Values and `target` are in `[-10^4, 10^4]`
- The solution must run in O(log n) time
