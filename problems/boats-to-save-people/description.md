Each element of `people` is a person's weight. A boat carries at most two people at once, and the total weight on a boat must not exceed `limit`. Return the minimum number of boats needed to carry everyone.

Constraints:
- `1 <= len(people) <= 5 * 10^4`
- `1 <= people[i] <= limit <= 3 * 10^4`
- Every person individually fits in a boat
