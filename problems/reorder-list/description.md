Given the `head` of a singly linked list `L0 -> L1 -> ... -> Ln`, rearrange it in place into `L0 -> Ln -> L1 -> Ln-1 -> L2 -> Ln-2 -> ...`. Nothing is returned.

Constraints:

- Rearrange by relinking nodes; do not change node values
- List length is up to 5 * 10^4
- A list with one or two nodes is unchanged
