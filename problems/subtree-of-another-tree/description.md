Given the roots `root` and `subRoot` of two binary trees, return `True` if some node in `root` has a subtree identical to `subRoot` in both structure and values, otherwise `False`. A node's subtree consists of that node and all of its descendants, so `root` itself qualifies.

Constraints:
- `root` has up to 2000 nodes; `subRoot` has up to 1000
- Node values are in `[-10^4, 10^4]`
