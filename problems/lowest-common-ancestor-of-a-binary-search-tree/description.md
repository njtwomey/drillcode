Given the `root` of a binary search tree and two nodes `p` and `q` in it, return the lowest common ancestor node: the deepest node that has both `p` and `q` as descendants. A node counts as a descendant of itself. Both nodes are guaranteed to exist in the tree.

Constraints:
- `2 <= number of nodes <= 10^5`
- All node values are unique
- `p != q`
