There are `n` nodes labeled `0` to `n - 1` and `edges` is a list of undirected edges `[a, b]`. Return `True` if these edges make the graph a valid tree (connected and acyclic), otherwise `False`.

Constraints:
- `1 <= n <= 2000`
- `0 <= len(edges) <= 5000`
- There are no self-loops or repeated edges.
