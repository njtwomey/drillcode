Given a non-negative integer `x`, return the integer square root of `x`: the largest integer `r` such that `r * r <= x`. The result is rounded down to a whole number.

Do not use a built-in exponent function or operator, such as `pow`, `**` or `sqrt`.

Constraints:
- `0 <= x <= 2^31 - 1`
- Floating-point square roots are not allowed, so the answer has to come from integer arithmetic
