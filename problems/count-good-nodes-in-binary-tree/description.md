Given the `root` of a binary tree, count the "good" nodes. A node is good if no node on the path from the root down to it has a larger value; that is, its value is greater than or equal to every ancestor's value. The root is always good. Return the number of good nodes.

Constraints:

- Between 1 and 100000 nodes
- Node values lie in [-10^4, 10^4] and may be negative
