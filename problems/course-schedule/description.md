There are `numCourses` courses labeled `0` to `numCourses - 1`. Each entry `[a, b]` in `prerequisites` means course `b` must be completed before course `a`. Return `True` if all courses can be finished, otherwise `False`.

Constraints:
- `1 <= numCourses <= 2000`
- `0 <= len(prerequisites) <= 5000`
- Prerequisite pairs are distinct.
