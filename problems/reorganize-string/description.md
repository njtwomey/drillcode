Given a string `s`, rearrange its characters so that no two adjacent characters are equal. Return any such rearrangement, or the empty string `""` if none exists.

The result must use exactly the characters of `s`, each with its original multiplicity.

Constraints:
- `1 <= len(s) <= 500`
- `s` contains only lowercase English letters
- Several rearrangements may be valid; any one is accepted
