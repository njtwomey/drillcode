Given `numbers`, sorted in non-decreasing order, find two different elements whose sum is `target`. Return their 1-based indices `[i, j]` with `i < j`. Exactly one valid pair is guaranteed to exist.

Constraints:
- `2 <= len(numbers) <= 3 * 10^4`
- Values and `target` lie in [-1000, 1000]
- The same element cannot be used twice
- Extra space must be O(1)
