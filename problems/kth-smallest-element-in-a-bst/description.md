Given the `root` of a binary search tree and an integer `k`, return the value of the `k`-th smallest node, counting from 1. `k` is always valid for the tree.

Constraints:
- `1 <= k <= n <= 10^4`, where `n` is the number of nodes
- `0 <= Node.val <= 10^4`
- Node values are unique
- Follow-up: the tree may be modified often and `k`-th queries repeated; consider how to keep queries fast
