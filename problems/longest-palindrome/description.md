Given a string `s` of English letters, return the length of the longest palindrome that can be built using the characters of `s`, each character used at most once and arranged in any order. You only return a length, not the palindrome.

Matching is case-sensitive, so `'a'` and `'A'` are different characters.

Constraints:
- `1 <= len(s) <= 2000`
- `s` consists of lowercase and uppercase English letters only
