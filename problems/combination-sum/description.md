Given an array of distinct integers `candidates` and an integer `target`, return all unique combinations of candidates that sum to `target`. Each candidate may be used any number of times. Two combinations are different if some value is used a different number of times; order within a combination and of the result does not matter. Return an empty list if none exist.

Constraints:
- `1 <= len(candidates) <= 30`
- Candidates are in `[2, 40]` and unique
- `1 <= target <= 40`
- The number of unique combinations is under 150 for every input
