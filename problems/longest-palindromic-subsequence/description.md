Given a string `s`, return the length of its longest palindromic subsequence. A subsequence keeps the original relative order of characters but may skip any of them, so it need not be contiguous. The result is the length only, not the subsequence itself.

Constraints:
- `1 <= len(s) <= 1000`
- `s` consists of lowercase English letters
- O(n^2) time is expected; O(n^3) or exponential search is too slow
