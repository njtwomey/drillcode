Given a binary array `nums` and an integer `k`, return the length of the longest contiguous run of `1`s you could obtain by flipping at most `k` zeros to ones. Only the length is returned; `nums` is not actually modified.

Constraints:
- `1 <= len(nums) <= 10^5`
- `nums[i]` is `0` or `1`
- `0 <= k <= len(nums)`
