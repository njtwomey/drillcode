The values of exactly two nodes in a binary search tree were swapped by mistake. Given the `root` of the damaged tree, restore it to a valid BST by fixing those two nodes. Return nothing; modify the tree in place. Node values are unique, and the tree structure itself is otherwise correct.

Constraints:

- Between 2 and 1000 nodes
- Node values lie in the 32-bit signed integer range
- A solution using constant extra space (beyond recursion or an explicit stack of height h) is preferred
