Given two non-negative integers `num1` and `num2` written as decimal strings, return their product, also as a decimal string. You must not use a built-in big-integer type or convert either whole string to an integer; work digit by digit. Neither input has leading zeros except the number zero itself, and the result must not have any either.

Constraints:
- `1 <= len(num1), len(num2) <= 200`
- Both strings contain only the digits `0-9`
