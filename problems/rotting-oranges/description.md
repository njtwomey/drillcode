Given a grid `grid` where `0` is an empty cell, `1` is a fresh orange and `2` is a rotten orange, every minute each fresh orange 4-directionally adjacent to a rotten one becomes rotten. Return the minimum number of minutes until no fresh orange remains, or `-1` if that never happens. Return `0` if there are no fresh oranges at the start.

Constraints:

- Grid is up to 10 x 10
- Several oranges may start rotten
