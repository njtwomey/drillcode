Given `intervals`, where `intervals[i] = [start, end]`, merge all overlapping intervals and return the resulting disjoint intervals sorted by start. Intervals that merely touch at an endpoint (such as `[1,4]` and `[4,5]`) count as overlapping. The input is unsorted.

Constraints:
- `1 <= len(intervals) <= 10^4`
- `0 <= start <= end <= 10^4`
