Given the `root` of a binary search tree and an integer `key`, delete the node whose value equals `key`, if there is one, and return the root of the resulting tree. The result must still be a valid binary search tree containing every other value. When a deletion can be done in more than one way, any valid result is accepted. If `key` is not in the tree, the tree is unchanged.

Constraints:

- Up to 10000 nodes
- Node values and `key` lie in [-10^5, 10^5]; values in the tree are unique
