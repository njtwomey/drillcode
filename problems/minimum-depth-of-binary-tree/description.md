Given the `root` of a binary tree, return its minimum depth: the number of nodes on the shortest path from the root down to a leaf. A leaf is a node with no children, so a node that has only one child is not a leaf. An empty tree has depth 0.

Constraints:

- Up to 100000 nodes
- Node values lie in [-1000, 1000]
- The tree can be very skewed, so recursion depth can reach the node count
