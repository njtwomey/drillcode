When a problem looks awkward, find the signal below and open the page. Each page says which variables to set up, what the loop looks like and what goes wrong.

| When the problem says or implies | Look at |
|---|---|
| Sorted input, or sorting is cheap and the answer is a pair or triple | `opposite-ends`, `binary-search-shapes` |
| Contiguous subarray or substring with a constraint | `sliding-window`; for sums, `dp-space-and-loop-order` (Kadane) |
| k-th, top k, k closest, k lists, running median | `heap-patterns` |
| Count the ways, minimum cost, is it possible, over a sequence of choices | `dp-finding-the-state` |
| All subsets, combinations, permutations, every valid arrangement | `backtracking-template` |
| Next greater or smaller element, how long until, maximum of each window | `monotonic-stack` |
| Fewest steps, spreading, nearest, unweighted shortest path | `bfs-shortest-paths` |
| Prerequisites, dependencies, a valid order | `topological-sort` |
| Connected groups, is the graph a tree, redundant edge | `union-find`, `graph-building-and-dfs` |
| A 2D grid of cells | `grid-traversal` |
| O(1) extra space demanded | `read-write-pointers`, `in-place-reversal`, `matrix-tricks`, `bit-tricks` |
| Intervals, meetings, ranges | `interval-patterns` |
| Prefixes of words, many word lookups, wildcard search | `trie-patterns` |
| Design a class with O(1) operations | `design-structures` |
| Palindromes | `expand-around-centre`, `opposite-ends` |
| The answer is a number and feasibility is cheap to test | `binary-search-on-answer` |
| Linked list and the head may change | `dummy-head` |
| Middle of a list, cycle, k-th from the end, array as pointers | `fast-slow-pointers` |
| For each element, something about both sides of it | `prefix-and-suffix-passes` |
| Tree: combine both children at each node | `tree-recursion-return-and-best` |
| Tree: per level, side views | `tree-bfs-by-level` |
| BST | `bst-invariant` |
| Serialise, rebuild from traversals, compare trees | `tree-serialise-and-rebuild` |
| Pairs, duplicates, grouping by a canonical form | `seen-before-insert` |
| Brackets, postfix, most recent unmatched | `stack-matching` |
| Bits, parity, without using arithmetic | `bit-tricks` |
| One tracked quantity seems to decide each step | `greedy-one-pass-invariants` (write down why first) |
| Count or find subarrays with a target sum, equal counts, or sums divisible by k | `prefix-sums-and-hashing` |
| Many range-sum queries on fixed data, or range additions | `prefix-sums-and-hashing` |
| Range sums with point updates in between | `fenwick-tree` |
| The missing or duplicate number in 1..n with O(1) extra space | `index-as-hash`, `fast-slow-pointers` |
| Cheapest or fastest route when edges have weights | `weighted-shortest-paths` |
| Connect everything at the minimum total cost | `minimum-spanning-tree` |
| Choose items to hit a target or fill a capacity; count the ways | `knapsack-patterns` |
| Compare two strings: edit distance, subsequences, interleaving | `two-string-dp` |
| Best value or number of paths through a grid; largest square | `grid-dp` |
| Tree where each node has a few states (taken or not, covered or not) | `tree-dp-states` |
| Tree paths with a target sum, or a property of the path from the root | `tree-top-down-state` |
| Split in halves, solve each, combine; sort a linked list; median of two arrays | `divide-and-conquer` |
| Evaluate or expand a nested or arithmetic expression in a string | `stack-expression-parsing` |
| Power, square root, or a number sequence that may loop | `math-tricks` |
